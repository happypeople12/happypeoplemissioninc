Happy People Mission multilingual landing page

Files:
- index.html — self-contained website (EN / UA / RU)
- hero.jpg — extracted visual used in the hero section

How to publish:
1. Upload this folder to Vercel, Netlify, GitHub Pages, or any static host.
2. Add the resulting public URL to Linktree.
3. The Support the Mission button is connected to the live Bluevine payment link.

The site is mobile responsive and remembers the visitor's language choice.
