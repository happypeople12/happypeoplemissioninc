# HAPPYPEOPLE MISSION — GitHub Pages App

Responsive static website based on the supplied Happy People Mission flyer.

## Included
- Same visual direction: white / black / gold
- EN / UA / RU language switcher
- PayPal donation button
- Bluevine bank donation button
- QR code removed
- Mobile responsive
- Ready for GitHub Pages

## Publish
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch.
5. Select branch `main` and folder `/(root)`.
6. Save.
7. Add the resulting GitHub Pages URL to Linktree.
