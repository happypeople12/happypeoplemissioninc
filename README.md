- Responsive mobile-first layout
- PayPal donation link

- Mission, foundation, current activities, and goals
- Design based on the supplied Happy People reference image
- Ready for GitHub Pages

## Publish on GitHub Pages
1. Create a new GitHub repository, for example: `happy-people-mission`
2. Upload all files from this folder to the repository root.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Click **Save**.
7. GitHub will give you a public URL like:
   `https://YOUR-USERNAME.github.io/happy-people-mission/`

Use that URL in Linktree.
